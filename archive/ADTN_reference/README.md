# ADTN Reference Archive

This directory contains historical ADTN reference implementations and scripts.
It is kept for provenance only and is not part of the current FitMoTN training,
evaluation, or RL runtime path.

Current FitMoTN code should use the main package modules such as `ADTN.py`,
`gate.py`, `model.py`, and `patching.py`.

Do not import this archive directory from main training, evaluation, or RL
entrypoints.
